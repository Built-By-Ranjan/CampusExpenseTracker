# Campus Expense Tracker and Budget Management System

A simple, menu-driven Python console application built as part of the **Computational Thinking and Programming (2026CSAE100)** collaborative project at **Bennett University (School of CSET)**.

## Features
- **Add Expense:** Record daily expenses with item name, category (`Food`, `Travel`, `Study`, `Other`), and amount.
- **View Expenses:** Display all logged expenses in an organized list along with total expenditure.
- **Category Summary:** Group spending by category and identify the highest-spending category.
- **Budget Check & Alert:** Set or update a monthly budget (default Rs. 5000.0) and check remaining balance or overspending alerts.

## Python Concepts Used
- Lists and Dictionaries (`expenses = []`, `summary = {}`)
- User-defined Functions (`add_expense()`, `view_expenses()`, `category_summary()`, `check_budget()`)
- Loops (`while`, `for`) and Conditionals (`if / elif / else`)
- Built-in Functions (`enumerate()`, `sum()`, `max()`, `float()`)
